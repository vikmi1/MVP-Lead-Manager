Lead-Capture Сервис
Как это работает — пример Autohaus Borgmann

Autohaus Borgmann — Essen-Altenessen

Многосалонный автодилер (Essen, Bottrop, Dülmen): продажа новых и б/у авто, сервисное обслуживание, запись на Probefahrt и Kundendienst. Каждый день сайт принимает десятки запросов на пробные поездки, запись на ТО и консультации.

🚗 3 филиала
📋 ~30–50 заявок/день
📬 Нет единой базы лидов
⚡ Заявки теряются по e-mail
Пошаговая схема
Как работает твой сервис
1

Клиент заполняет форму на сайте Autohaus

Покупатель хочет записаться на Probefahrt или задать вопрос по конкретному авто.

ВХОД → POST /lead (JSON)
{
  "name": "Klaus Müller",
  "contact": "k.mueller@email.de", // обязательно!
  "source": "Probefahrt-Formular",
  "comment": "Interessiert an VW Tiguan 2024, Mo-Fr"
}
name — имя клиента contact — email или телефон source — откуда пришёл comment — дополнительно
2

Flask-сервис принимает и валидирует запрос

Твой Python-сервис проверяет входящий JSON и фильтрует некорректные данные.

Валидация (Flask endpoint)
✓ JSON парсится без ошибок ✓ поле contact присутствует ✓ contact не пустой
HTTP 400 Нет поля contact или невалидный JSON → отказ с сообщением об ошибке
HTTP 500 База недоступна → запись в events.log, ответ об ошибке
3

Заявка сохраняется в базе данных SQLite

Каждый лид записывается в таблицу leads с временной меткой.

База данных — таблица leads
ПолеТипОписание
idINTEGER PRIMARY KEYавтоинкремент
created_atDATETIMEавтоматически при записи
nameTEXTимя клиента (необяз.)
contactTEXT NOT NULLemail/телефон — ОБЯЗАТЕЛЬНО
sourceTEXTисточник заявки
commentTEXTкомментарий
consentBOOLEANсогласие DSGVO
4

Уведомление менеджеру автосалона

Сразу после сохранения система уведомляет ответственного менеджера о новой заявке.

📄 Вариант A: events.log

Каждый лид дописывается в файл с датой/временем. Менеджер видит все заявки хронологически.

[2026-06-24 23:05:12] NEW LEAD
contact: k.mueller@email.de
source: Probefahrt-Formular

📧 Вариант B: E-Mail

Python (smtplib) отправляет письмо менеджеру с деталями заявки сразу при поступлении.

To: manager@borgmann.de
Subject: Neue Anfrage
Probefahrt: Klaus Müller
Tel/Email: k.mueller@...
5

Ответ сайту клиента

Твой API возвращает успешный JSON-ответ форме на сайте автосалона.

ВЫХОД → HTTP 200 OK
{
  "status": "ok",
  "message": "Ihre Anfrage wurde gespeichert",
  "lead_id": 42
}
✓ lead сохранён в БД ✓ менеджер уведомлён ✓ форма показывает "Vielen Dank!"
6

Обработка ошибок

Все исключения логируются — ни одна заявка не теряется незаметно.

Логирование ошибок
400: нет contact → {"error":"contact required"} 400: плохой JSON → {"error":"invalid JSON"} 500: БД упала → запись в log + {"error":"db error"}
Немецкое законодательство

Поле consent

В БД и в JSON — логируй явное согласие клиента на обработку данных (checkbox на форме)

Срок хранения

Хостинг в ЕС

🔒

HTTPS

Все запросы только по HTTPS (Let's Encrypt), данные в транзите зашифрованы
